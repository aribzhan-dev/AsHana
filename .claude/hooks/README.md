# Hooks

Исполняемые hooks не установлены и не активированы. Пользовательский запрет GitHub
зафиксирован в AGENTS.md и privacy-and-git.md; не считать этот каталог техническим блокировщиком.

Возможное будущее применение: локальная проверка форматирования и поиск секретов перед
явно разрешённой публикацией. Конкретный формат hook зависит от редактора и должен быть
проверен по его документации. Hook не должен отправлять данные наружу, читать реальные .env,
автоматически делать commit/push или изменять глобальные настройки пользователя.
