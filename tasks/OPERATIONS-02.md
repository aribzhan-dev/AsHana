# OPERATIONS-02 — возвраты, долги, отчёты, «с собой», тестовая карта

Статус: выполнено 22.10.2026 по запросу владельца. [ADR-0019](../docs/architecture/decisions/0019-operations-v2.md).

Решения владельца: онлайн-возврат остаётся прежним (отмена до комплектации); добавить возврат
на кассе и долги поставщикам; первый набор из 10 отчётов + «Долги поставщикам»; тестовая
оплата принимает только тестовые карты; приборы гость добавляет сам и платит за них.

- R08/R09: возврат по чеку (`pos.refund`), тестовая форма карты без передачи реквизитов.
- R04/R06: общий справочник категорий; постоянные покупные товары во всех периодах.
- R02: выбор «В столовой / С собой», приборы и упаковка как товары категории «Приборы».
- R10: ТОП, ABC, не продавались, возвраты, инвентаризация, расходы, кассовая книга, долги,
  почасовая сводка; новая страница отчётов с меню видов.
- R11–R13: вход сотрудников по `/admin`, без ссылки на сайте; «Выйти из кабинета» в меню;
  страница заказов гостя по центру на компьютере.

Результаты — [текущий этап](current-sprint.md).
