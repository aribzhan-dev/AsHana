# CATALOG-01 — меню и периоды питания

Выполнен 21.10.2026 по запросу владельца. Требования R01/R06/R11–R18.

Приёмка: управляющий создаёт/редактирует периоды по дате и времени Алматы; меню содержит
собственную продукцию или покупные товары, описание порции и цену KZT в целых тиынах.
Публикация/снятие доступны отдельно для периода и позиции. Устаревшее редактирование
отклоняется, повтор запроса не создаёт дубль, изменения имеют неизменяемый аудит.
Публичное меню без входа показывает только опубликованные позиции активных периодов,
с положительным свободным остатком пригодных готовых партий. Сырьё не публикуется.
Остатки суммируются по партиям без изменения склада; просроченное, приостановленное и
зарезервированное количество не включается. Текущие серверные время/цена/остаток авторитетны.
Русские формы, light/dark, 360–1440 px, пустые/загрузочные/ошибочные состояния обязательны.
Оформление заказа и резервирование остаются в ORDERS-01.

План: модель/порты/миграция → API и права → управление и гостевое меню → тесты и review → документы/стенд.

Результат: 91 backend (22 PostgreSQL integration), 36 Vitest, 24 Chromium E2E.
Самостоятельный review и проверка обеих тем выполнены. Доказательства и ограничения —
[текущий этап](current-sprint.md); инструкция — [работа с меню](../docs/engineering/catalog-usage.md).
