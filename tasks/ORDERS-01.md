# ORDERS-01 — гостевые заказы и резервы

Реализовано по запросу владельца 21.10.2026. R02/R04, R01/R06 и R11–R18.
Дополнительно: компактный focus вместо синего внешнего outline; подготовка Telegram-уведомлений.

Приёмка:
- Корзина без регистрации, непрозрачный гостевой HttpOnly credential, чужой заказ недоступен.
- Серверные снимки названия/порции/цены; проверка публикации и времени периода, cutoff/слота.
- Оформление + все готовые партии + место слота + аудит + replay атомарны; гонки последней порции/слота.
- Отмена/истечение освобождают резерв ровно один раз; сырьё повторно не списывается.
- Гость видит свои заказы, сотрудник — разрешённый список; polling восстанавливает состояние.
- Telegram — отдельная доставка сохранённого события, сбой не откатывает заказ; без секретов/телефона.
- Русские формы, ошибки, обе темы, адаптивность, проверки реального PostgreSQL и браузера.

План: focus → модель и контракты → транзакции/API → корзина/слоты/экраны → Telegram adapter →
проверки гонок/rollback/ownership → review/документы → обновление локального стенда.

Выбран mock-flow; реальные платежи/выдача не входят в этап. Результаты проверок — current-sprint.md.

Уточнение владельца: приём закрывается за 15 минут до начала выдачи. Остальные предложенные
значения пока рабочие настраиваемые defaults. Вопрос последней порции обязательно проверяется гонкой.

Новое уточнение: настоящий заказ записывается в orders только ПОСЛЕ успешной оплаты.
До оплаты — checkout_drafts с временным резервом/слотом, без заказа в staff/Telegram.
Выбран mock: для проверяемого сквозного пути в этот этап добавляется минимальный сценарий
mock-подтверждения/отказа/таймаута и атомарного создания заказа. Реальные деньги не принимаются.

Последнее уточнение владельца заменяет прежние 30 минут: оплатить минимум за 15 минут до
получения, полный резерв 5 минут после «Заказать», кухня видит только оплаченные заказы
в порядке ближайшего получения. Слот закрывается для нового checkout за 20 минут, чтобы
не сокращать резерв. Кнопка и обратный отсчёт отражают эту последовательность.
