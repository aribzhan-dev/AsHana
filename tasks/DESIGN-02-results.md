# Текущий этап: DESIGN-02 выполнен

22.10.2026. [Задача](DESIGN-02.md), [ADR-0018](../docs/architecture/decisions/0018-qr-pickup.md),
[демо-данные](../docs/engineering/demo-data.md), [результаты PRODUCTS-02](PRODUCTS-02-results.md).

## Реализовано

- Решение владельца: оплата остаётся mock, реальный провайдер не подключается (PAYMENT-01 закрыт).
- Выдача по QR: QR-чек в «Мои заказы» и вкладка «QR»; страница `/staff/scan` с камерой (jsQR)
  и полем для ручного сканера. `GET /api/v1/orders/staff/{id}` (kitchen.read) без кода получения
  и без неоплаченных оформлений. Выдача — прежний переход `completed` с кодом, версией и ключом.
- Новый дизайн по макету владельца, бренд ashana: жёлтый акцент, логотип, светлая и тёмная темы.
  Гость: hero, категории, карточки с иллюстрациями, окно товара, корзина-лист со степпером и
  выбором времени, QR-чек со статусом. Кабинет: тёмное боковое меню, сводка «Новые /
  Собираются / Готовы». Меню разделено по дням («Сегодня», «Завтра»), чтобы блюда соседних
  периодов не повторялись в одном списке. Фотографии блюд заменены иллюстрациями: загрузка
  изображений не реализована.
- Убраны 15 поясняющих абзацев (лимиты, повтор запроса, обновление каждые 15 секунд и т. п.);
  серверные проверки и тексты ошибок не изменены.
- Локальный стенд: `.env` со случайными паролями, администратор из `secret/admin.json`,
  `scripts/seed_demo.py` (24 товара, 7 выпусков, 12 позиций меню на 7 дней, слоты).

## Проверки

- **134 backend** (pytest) на изолированном стенде, включая новую PostgreSQL-проверку
  поиска заказа для сканера: права, 401/404, скрытый код, неоплаченное оформление.
- Ruff/format backend и `scripts/seed_demo.py` — чисто. Mypy выдаёт 57 ошибок в шести
  PostgreSQL-тестах; столько же без изменений DESIGN-02 — это прежнее состояние, не исправлялось.
- **60 Vitest**: разбор QR, QR только у активного заказа гостя, сканер выдаёт с кодом из QR,
  чужой QR и отсутствие права выдачи. ESLint, Prettier, TypeScript, build, git diff --check.
- **32 Chromium E2E** на изолированных стендах `scripts/check_foundation.py --identity`
  (последний прогон — после группировки меню по дням): гостевой заказ через новую корзину,
  кухня, отмена, новая проверка выдачи по QR на `/staff/scan`, темы и ширины 360–1440.
  Первый прогон выявил гонку теста с индикатором загрузки и страницу меню после reload;
  исправлены тестовые помощники, код приложения не менялся.
- Браузер вручную (390/800, обе темы): меню → окно товара → корзина → время → оплата →
  QR-чек → кухня «Собирается/Готов» → `/staff/scan` → «Заказ выдан».

## Границы

на планшете в локальной сети без HTTPS камера недоступна, ручной сканер работает.

Пароли не выводились. Git-мутаций и публикаций не было.
