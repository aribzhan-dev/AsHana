# TELEGRAM-01 — уведомления о заказах в Telegram

Статус: код готов 23.10.2026; живое подключение ждёт токен бота и группу владельца.

- Понятные сообщения: короткий номер, «с собой»/«в столовой», время выдачи, блюда, итог.
- Без персональных данных, кода получения и UUID; связь с заказом — `notification_outbox.subject_id`
  (миграция `0015_outbox_subject`).
- Старые события (старше 6 часов) не отправляются после подключения.
- CLI `python -m ashana.bootstrap.telegram chats|check`: найти ID группы, проверить бота,
  отправить тестовое сообщение; токен не печатается.
- Инструкция — [orders-usage.md](../docs/engineering/orders-usage.md#telegram).
