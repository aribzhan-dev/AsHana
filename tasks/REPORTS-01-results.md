## Реализовано

- `/staff/reports`, reporting.read для отчётов и справочников. READ ONLY UoW,
  shared identity lock, никакой записи в учёт из чтения отчёта.
- Продажи по событиям оплаты/выдачи/отмены/expiry. POS success — одновременно оплачен/выдан;
  failed/timeout не входят. Отмена считается один раз по cancelled, возврат — paid_cancelled.
  Количества оплачено/выдано/отменено/истёк резерв раздельны. Суммы demo/real не объединяются.
- Фактическое производство; текущий остаток on_hand/reserved/available/blocked;
  списания отдельно от недостачи/излишка пересчёта. Производство и продажа не повторяются в списаниях.
- Даты включительны по Алматы, до 366 дней. Товар везде; период/канал/mode только в продажах.
  Для остатка дата не применяется, указано время актуальности. Исторический остаток не имитируется.
- Pagination и полные итоги в одном SQL statement/MVCC snapshot; количества отдельно по единицам.
  Тиыны и Decimal передаются строками, UI форматирует большие суммы через BigInt без потери точности.
- Формы, empty/loading/error/retry, темы и мобильные карточки. Русские тексты, no-store.
  Новые таблицы/миграции для отчётов не нужны; схема остаётся 0009_pos.
