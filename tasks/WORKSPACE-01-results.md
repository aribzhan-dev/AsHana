## Реализовано

- Постоянная навигация по backend permissions; компактный desktop и горизонтальная мобильная
  навигация. `/staff` — обзор, `/staff/profile` — сессии и выход, `/staff/team` — сотрудники/роли.
- Обзор за даты Алматы: точные денежные итоги, топ-5 и нижние 5 по оплаченной продукции,
  включая готовые товары без продаж. Один SQL snapshot, reporting.read, READ ONLY.
- Полный список сотрудников; новый каталог ролей с названием, кодом, разрешениями и version.
  Новые роли/редактирование, назначения, отзыв сессий при изменении прав, аудит.
  admin сохраняет identity.manage, последний admin защищён. DELETE ролей не добавлен.
- Касса: поиск по всему загруженному меню, категории, компактные карточки/чек. Платёжные
  кнопки отказа/таймаута убраны; негативные ответы и потерянный результат проверяются тестами.
- Меню: категория в форме, подсказки стандартных категорий, поиск внутри страницы периода,
  публикация/снятие прямо из карточки с version и idempotency key.
- Товары: первая вкладка справочника, поиск и фильтр типа. Формы рецептов шире,
  select/input одинаковой высоты. Имя отклоняет цифры с немедленной ошибкой;
  телефон +7 неизменяемый, десять цифр после него, вставка форматированного номера, без букв.
- DEMO-тексты убраны из интерфейса. Исторические seed-подписи отображаются нейтрально
  по точному соответствию; исходные immutable записи не переписываются.
  Mock/real и прежние ограничения оплаты/склада остаются в данных и backend.
