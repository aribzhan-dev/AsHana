# AI-разработка, навыки и доступ

Точка входа: AGENTS.md. `.claude` повторяет удобную структуру со скриншота, но не копирует
SSS Platform. `.agents/skills` — канонические локальные навыки; `.claude/skills` — ссылка на них.
Факт наличия файла не означает, что конкретный редактор автоматически его загрузит.
В Codex/другом инструменте при необходимости явно открыть SKILL.md.

## Локальные навыки

- `ashana-feature`: провести бизнес-сценарий через слои, сохранив инварианты.
- `ashana-inventory`: проверить выпуск, остатки, резервы и гонки кассы/online.
- `ashana-ui`: русские формы, KZ-валидация, темы, адаптивность и password toggle.
- `ashana-review`: проверить готовое изменение и доказательства тестов перед отчётом.

Роли в `.claude/agents` — справочники ответственности, не автономно запущенная команда.
Commands — ручные Markdown-подсказки. Hooks — документированный план, без активного исполняемого кода.

## Навыки текущего сеанса

Для подготовки использованы skill-creator и architecture-designer.
В среде также доступны FastAPI/React/PostgreSQL/TypeScript, security и testing skills;
это средства будущей работы, не зависимости проекта и не доказательство выполненной проверки.
Полный список глобальных навыков изменчив: не копировать его как обязательный каталог проекта.
Выбирать подходящий навык по задаче и читать его инструкции перед применением.

## Фактические возможности

На момент подготовки доступны файловые/терминальные инструменты с ограничениями sandbox,
поиск публичной документации и Context7, инструменты браузера и управления локальными чатами.
Запись в Desktop/AsHana потребовала разрешённого расширения sandbox; открытие файла в UI
не меняет автоматически рабочую папку чата. При следующем сеансе доступ нужно проверить заново.

Это не означает доступ к GitHub, платёжному кабинету, SMS, production DB или аккаунтам владельца.
GitHub не подключался, push/pull/merge не выполнялись. Секреты не исследовались.
Браузер/коннекторы использовать только в пределах задачи, не для публикации приватных документов.
Для продолжения открыть AsHana как рабочий проект и начать с tasks/current-sprint.md.
