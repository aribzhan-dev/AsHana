# Приход, остатки и касса

## Накладная

Откройте «Приход» → «Новая накладная». Введите номер и дату по времени Астаны,
выберите поставщика, склад и способ полной оплаты. Через «Добавить» можно создать
недостающую запись справочника, не уходя со страницы.

Для каждой строки выберите сырьё или покупной товар, количество, цену за базовую
единицу и срок годности. «Создать товар» открывает форму прямо в накладной и подставляет
созданную позицию. Собственная готовая продукция поступает через выпуск, не закупку.

«Дополнительные расходы» — доставка и прочие затраты этой накладной. Показываются
стоимость товаров, расходы и сумма полной оплаты. Долгового остатка нет.
Цена × количество округляется до тиына для каждой строки; backend пересчитывает сумму.
Расходы не распределяются по партиям и не изображаются себестоимостью блюд.

«Провести приход» сохраняет все партии, движения, накладную и аудит одной транзакцией.
Повтор того же запроса возвращает результат без дубликата. Повтор номера у того же
поставщика отклоняется. Проведённые документы неизменяемые; склад корректируется
отдельным списанием или инвентаризацией. Пока форма не отправлена, склад не меняется.
Форма сохраняется при её закрытии на той же странице; перезагрузка страницы очищает
непроведённый ввод. При потере ответа повторите запрос с неизменёнными данными.

## Товары и остатки

«Товары» — справочник, поиск и штрихкод. Необязательный штрихкод покупного товара:
8–14 цифр, уникален, ведущие нули сохраняются. Его можно изменить отдельной кнопкой;
конкурентное изменение требует обновления данных.

«Остатки» — физическое количество, резерв и доступно. Поиск по названию и выбор склада
применяются на сервере до пагинации. Подробности партии — по значку глаза, действия
с партией и история движений остаются рядом. Старые одиночные приходы доступны здесь;
они не превращаются задним числом в новые накладные. Старые партии и собственный выпуск
относятся к основному складу. Склады находятся в одной столовой; касса/сайт используют
единый пригодный свободный остаток. Перемещения между складами не добавлены.

## Касса и история

«Касса» — товары, текущий чек, выбор способа оплаты. После успешной оплаты краткое
уведомление; полная история в «История продаж». Фильтр «Касса · офлайн» показывает кассовые
попытки с результатом, «Сайт · закрытые заказы» — завершённые/отменённые заказы.
Активные оплаченные заказы остаются во «Входящих заказах», ближайшие по времени первыми.
Чтение сайта требует kitchen.read; кассовая история — pos.sell.

Во вкладке кассы «Списание» выберите партию, количество и причину. Требуется право
inventory.writeoff либо inventory.manage; типовые кассир/управляющий получили первое.
Доступны только готовые/покупные товары. Нельзя списать активный резерв, увеличить остаток
или выполнить пересчёт через кассу. Просроченные свободные товары списываются тем же путём.
Движение попадает в существующий отчёт списаний. Два одновременных изменения одной версии
не выполнятся оба; повтор ключа не создаёт второе списание.

«Настройки» содержит способы оплаты, поставщиков и склады; доступ inventory.manage.
Наименование способа сохраняется в чеке/накладной. Способ оплаты не подключает эквайринг:
режим остаётся mock, реальные денежные отчёты по-прежнему отделены.

## Компактный интерфейс

В отчётах, остатках, рецептах и выпусках основные значения видны сразу, подробности
открываются кнопкой с глазом. Слоты выдачи — компактная сетка с выбором дня и часа.
Для Астаны сохранён технический часовой пояс Asia/Almaty (UTC+5), существующие UTC-моменты
не сдвигаются. Правила пяти минут резерва и оплаты за 15 минут до выдачи сохранены.

## Долги поставщикам (22.10.2026)

В накладной поле «Оплачено сейчас» по умолчанию пустое — значит, оплачено полностью.
Если оплачена часть, остаток становится долгом и виден в списке накладных. Кнопка
**Оплатить долг** записывает оплату (сумма, способ, дата, комментарий); можно платить частями,
переплатить нельзя. Отчёт «Долги поставщикам» показывает текущий долг по поставщикам.

## Категории

Категория выбирается из общего списка. «＋ Новая категория…» создаёт название один раз для
всех сотрудников; список также виден в «Настройки → Категории».
