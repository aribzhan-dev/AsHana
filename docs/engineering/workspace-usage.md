# Рабочий кабинет

- `/staff`: обзор за выбранные даты Алматы; поступления, сумма выдачи, возвраты, число товаров
  с оплатами. Рейтинги по количеству оплаченных порций/штук, не по прибыли. Нижний рейтинг включает
  готовые и покупные товары без продаж. Отмены/возвраты отдельно, не вычитаются из числа оплат.
- `/staff/profile`: имя, логин, роли, выход и собственные сессии.
- `/staff/team`: список сотрудников, создание и поиск; вкладка «Роли и доступ» — новый код,
  название и права роли. Код после создания неизменяемый, название и права редактируются.
  При смене прав сотрудники входят заново. У admin сохраняется управление сотрудниками.
- `/staff/orders`: оплаченные входящие заказы, ближайшая выдача первой. Настройка слотов
  свёрнута под отдельным раскрывающимся блоком; комплектация не означает повторное производство.
- `/staff/pos`: поиск по всему опубликованному доступному меню, категории, компактный чек.
  Касса и онлайн используют прежний общий остаток. Неизвестный результат сохраняет ключ повтора.
- `/staff/catalog`: дата, периоды, поиск внутри страницы выбранного периода; категория,
  цена и описание в форме позиции, «Показать на сайте / Скрыть с сайта» прямо в карточке.
  Публикация периода и пригодный свободный остаток по-прежнему обязательны для гостевого меню.
- `/staff/inventory`: товары с поиском/типом, отдельные вкладки прихода и партий.
- `/staff/production`: расширенная форма рецепта, поля и единицы одинаковой высоты.

Навигация показывает только доступные разделы; права проверяются на сервере независимо от UI.
Телефон: неподвижный +7 и десять цифр; вставка полного форматированного номера поддерживается,
буквы/лишние цифры отклоняются. Только KZ MOBILE по метаданным, поле остаётся необязательным.
Имя не принимает цифры; Unicode, казахские буквы, дефис и апостроф поддерживаются.

Оплата всё ещё mock; реальные реквизиты не принимаются, провайдер не подключён.
DEMO-надписей в рабочих действиях больше нет по запросу владельца.

## Сотрудники: просмотр, изменение, блокировка, удаление (24.10.2026)

В «Сотрудники и роли» у каждого сотрудника три кнопки:

- **Просмотр** — карточка: имя, никнейм, логин, телефон, Telegram (ссылка), роли, статус, дата
  создания. В карточке: «Заблокировать / Разблокировать» и «Удалить».
- **Изменить** — имя, никнейм, телефон, Telegram (`@username`, необязательно), роли и новый
  пароль, если сотрудник его забыл.
- **Удалить** — после подтверждения. Сотрудник сразу выходит из системы и больше не входит,
  исчезает из списка. Его имя остаётся в истории (накладные, продажи, журнал), поэтому логин
  остаётся занятым. Физически запись не стирается: на неё ссылаются документы.

Блокировка — временная: сотрудник не может войти, все его сессии завершаются; разблокировка
возвращает доступ. Себя заблокировать или удалить нельзя, последнего администратора — тоже.
Поиск по логину открывает ту же карточку. Миграция `0020_staff_profile` (Telegram, `deleted_at`).
