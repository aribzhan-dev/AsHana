# HTTP, ошибки и логи

Предложенный prefix `/api/v1`. OpenAPI — контракт DTO, а не замена бизнес-требованиям.
Ошибки: `code` (английский стабильный идентификатор), `message` (русский),
`field_errors` (русские сообщения по полям), `request_id`.
Примеры: OUT_OF_STOCK — «Блюдо закончилось»; SLOT_FULL — «Выберите другое время»;
RESERVATION_EXPIRED — «Время оплаты истекло. Оформите заказ заново».

400 — некорректный запрос; 401 — нет сессии; 403/404 — запрет по политике раскрытия объекта;
409 — конфликт остатка/слота/состояния; 422 — ошибки полей; 429 — ограничение частоты;
500 — «Не удалось выполнить действие» без stack trace клиенту.

Валидационные исключения Pydantic переводить централизованно; не возвращать input password
в detail и не выводить весь body в лог. Структурированные логи с operation, request_id,
entity_id, outcome; пользовательские данные минимизированы.
Аудит бизнес-операций хранить отдельно от диагностических логов.
