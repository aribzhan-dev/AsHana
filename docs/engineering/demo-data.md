# Демонстрационные данные локального стенда

22.10.2026 по запросу владельца: обычный стенд `docker compose` на порту 8080.
Оплата остаётся mock; товары, цены, нормы и сроки — демонстрационные, не фактическая поставка.

## Администратор

Создаётся CLI `python -m ashana.bootstrap.admin` (роли admin + manager). Логин и пароль хранятся
только в игнорируемом `secret/admin.json` (права 0600), не в исходниках и не в документации.

## Наполнение

```sh
python3 -I scripts/seed_demo.py --credentials secret/admin.json
```

Скрипт входит под администратором и вызывает обычный HTTP API: те же use cases, аудит,
idempotency и права, что у интерфейса. Повторный запуск в тот же день не дублирует меню.

- поставщик «ТОО «Продукты Астана»», одна накладная прихода с расходами;
- 12 позиций сырья, 5 покупных товаров со штрихкодами, 7 блюд собственного производства;
- по одному рецепту и выпуску каждого блюда (сырьё списано при выпуске);
- период «Меню столовой» на каждый из 7 дней (07:00–23:59 Астана), 12 позиций с категориями
  Комплексы, Супы, Салаты, Гарниры, Выпечка, Напитки, Десерты;
- слоты получения по 10 минут, вместимость 10, оплата не позднее чем за 15 минут.

Продажи и заказы для украшения отчётов не создаются.
22.10.2026 периоды текущего стенда дополнительно расширены до 07:00–23:59 и добавлены
вечерние слоты, чтобы меню было доступно при вечерней проверке.
