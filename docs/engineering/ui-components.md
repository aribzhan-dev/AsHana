# Общие компоненты UI-01

Каталог: `frontend/src/shared/ui/`. React/TypeScript, CSS tokens, русские словари
`shared/locales/`. Формы identity выделены в `features/identity/`; PageShell используется
на главной и в кабинете. Общие компоненты не принимают решений о правах пользователя.

| Компонент | Контракт и поведение |
|---|---|
| Button / IconButton | type=button по умолчанию; явный submit; loading блокирует повторы, aria-busy; иконка с доступным именем |
| Input | Постоянная подпись, placeholder, hint/error с отдельными ID, aria-invalid, native required/disabled |
| PasswordInput | По умолчанию скрыт; eye toggle не отправляет форму, сохраняет значение и фокус при pointer-нажатии; autocomplete |
| PhoneInput | Иконка телефона, KZ placeholder, inputmode=tel; формат проверяется при submit и на backend |
| Select | Нативный выбор, связанная подпись/подсказка/ошибка, клавиатура |
| QuantityInput | Строковое значение сохраняет IME/редактирование/вставку; +/- ограничены min/max; отдельный quantityError проверяет целые числа |
| CheckboxGroup | Fieldset/legend, несколько значений, disabled и общая ошибка; роли передаются feature-адаптером |
| Dialog | Native showModal, Escape, возврат фокуса, закрытие блокируется во время изменения; подпись и описание |
| Alert / Toast | Ошибка role=alert с фокусом, успешный результат role=status; toast закрывается вручную и не исчезает до прочтения |
| Loading / Empty / Error | Явные состояния загрузки/пустого результата/повтора запроса; внутренние ошибки не выводятся |
| Card / Badge | Семантическая секция и метка; стили обеих тем |
| ThemeSelect | Компактная icon button, диалог выбора light/dark/system, сохранение предпочтения и реакция на системную тему |
| PageShell | Бренд, навигация, skip link, main и footer; единая адаптивная оболочка |

## Правила использования

- Не заменять подпись placeholder-ом. Ошибка остаётся связанной с полем, включая ответ API.
- Во время отправки блокировать связанные поля и submit. При ошибке сохранять введённые данные;
  пароль очищать после успешного создания сотрудника, не показывать его в toast или логах.
- Числовой компонент не является серверной проверкой остатка/цены. В текущих бизнес-экранах
  его ещё нет; он проверен отдельно для следующих модулей.
- Select применяется в формах INVENTORY-01. Для Decimal-количеств используется общий Input
  с отдельной валидацией и выбором единицы; QuantityInput предназначен для целых порций. ProductCard/OrderStatus отложены до предметных данных соответствующих модулей.
- Touch targets от 44px; ширины 360/390/768/1280/1440. Кнопки и сессии на мобильном
  занимают доступную ширину, страницы не требуют горизонтального скролла.
- Native dialog удерживает фокус; Escape возвращает его инициатору. Бизнес-действия с
  отзывом сессий требуют понятного подтверждения в интерфейсе.
- Уважать prefers-reduced-motion. Токены light/dark покрывают фон, контраст, ошибку, успех,
  focus и disabled. Полное соответствие WCAG требует отдельного аудита.
