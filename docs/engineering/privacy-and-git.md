# Приватность и GitHub

Подтверждённое ограничение владельца: не выполнять push/pull/merge и аналогичные операции
с его GitHub без отдельного явного разрешения. Репозиторий Git существует; локальные commit,
изменение remote, PR, upload, публикация Pages/site также выполняются только по просьбе владельца.

Конфиденциальны: реальные `.env`, `secret/`, DB credentials, токены, дампы и резервные копии,
результаты тестов, логи, traces, screenshots с данными — всё это в `.gitignore`.
Решение владельца 23.10.2026: документация (`docs/`, `tasks/`), README и инструкции агентов
(`AGENTS.md`, `CLAUDE.md`, `.claude/`, `.agents/`) могут попасть на GitHub. Локальные настройки
инструментов (`.claude/launch.json`, `.claude/settings.local.json`) исключены.
Шаблоны .env.example допускаются только с заглушками и только в явно согласованном списке.

Если владелец попросит публикацию:
1. Подготовить локальный результат и точный список разрешаемых файлов.
2. Проверить секреты и персональные данные, включая историю, если Git позже появится.
3. Уточнить разрешение на конкретные документы/артефакты, не покрытые запросом.
4. Выполнить только конкретно разрешённую операцию.

Ignore-файл не является контролем доступа: уже отслеживаемые файлы, force-add и ручной upload
могут его обойти. Hooks пока не установлены. Не обещать техническую блокировку всех публикаций.
Не копировать приватный проект в внешние сервисы для генерации/анализа без разрешения.
В документационные поиски отправлять только общие вопросы по публичным библиотекам.
