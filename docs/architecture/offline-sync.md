# Работа при потере связи

Первая версия online-only для заказов, резервов, оплаты, кассы и выдачи.
Без подтверждения сервера не показывать успешный заказ или продажу.
Можно сохранить локальную корзину без персональных секретов; её наличие не резервирует товар.

При неизвестном исходе запроса повторить с тем же idempotency key или запросить статус.
Показывать «Нет соединения. Проверяем статус заказа», а не автоматически создавать новый заказ.
После reconnect обновить остатки, очередь и статусы из API.

Offline-продажи не включены: они могут продать уже зарезервированную последнюю порцию.
Будущее offline-решение требует отдельного распределения остатков и правил конфликтов.
