# ADR-0003: Изолированная mock-оплата

Статус: **Mock подтверждён; протокол предложен**. Дата: 20.10.2026.

## Контекст
Нужно демонстрировать checkout без банковской интеграции.

## Решение
Явный demo mode, без реквизитов карт; payment port; success/failure/cancel/timeout; TTL; суммы из заказа; отдельные отчёты.

## Альтернативы
Реальный провайдер пока вне объёма. Только анимация success без server state не проверяет согласованность.

## Последствия
Можно проверить сценарии без денег; нельзя считать demo-paid доказательством оплаты в реальном пилоте.
