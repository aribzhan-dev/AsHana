# ADR-0005: Надёжные уведомления и online-only

Статус: **Предложено**. Дата: 20.10.2026.

## Контекст
Сбой WebSocket не должен терять заказ; offline-касса может конфликтовать с online-резервом.

## Решение
Outbox в PostgreSQL, идемпотентный worker, HTTP восстановление; продажи и выдача только с подтверждением сервера.

## Альтернативы
Только in-memory события теряются при рестарте. Kafka и offline-sync пока избыточны.

## Последствия
Восстанавливаемость событий; требуется фоновая обработка, мониторинг задержки и интернет для операций.
