# ADR-0004: Серверные cookie-сессии

Статус: **Реализовано для локального IDENTITY-01**. Дата: 20.10.2026.
Технический выбор реализации, а не отдельное утверждение всех деталей владельцем.

## Контекст
Первый клиент — веб-приложение одного origin, нужны отзыв сессии и роли.

## Решение
Непрозрачный session token в HttpOnly cookie, hash в PostgreSQL; CSRF защита, Argon2id, backend permissions.

## Альтернативы
JWT bearer подходит иным клиентам, но добавляет управление отзывом; localStorage повышает последствия XSS.

## Последствия
Простой отзыв; запрос к сессии на backend и обязательная CSRF защита.

Реализовано для локальных сотрудников в IDENTITY-01. Публичной регистрации нет;
ограничения владельца и гостевой сценарий уточнены в [ADR-0007](0007-staff-only-identity.md).
