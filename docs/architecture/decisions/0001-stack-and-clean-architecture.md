# ADR-0001: Стек и Clean Architecture

Статус: **Стек и принцип подтверждены; модульная структура предложена**. Дата: 20.10.2026.

## Контекст
Нужны согласованные заказы, склад и понятная база для AI-разработки.

## Решение
Python/FastAPI, React/TypeScript, PostgreSQL, Docker. Один модульный backend с направлением зависимостей к domain/application.

## Альтернативы
Vue/другой backend не соответствуют выбору владельца. Микросервисы усложняют атомарный checkout.

## Последствия
Простой локальный запуск и общие транзакции; взамен требуется дисциплина модульных границ и совместный деплой.
