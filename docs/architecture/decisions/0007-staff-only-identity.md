# ADR-0007: аккаунты только для сотрудников

Дата: 20.10.2026. Статус: продуктовые ограничения подтверждены владельцем;
техническая реализация выполнена в IDENTITY-01.

Клиент открывает сайт и оформляет заказ без регистрации и входа. Владелец подтвердил
только мобильные номера Казахстана. Предыдущие упоминания публичной регистрации отменены.
Серверные сессии и роли из ADR-0004 применяются к сотрудникам. В UI-01 владелец
уточнил вход по логину и паролю, телефон только для связи: [ADR-0008](0008-staff-login-and-ui.md).

Первый администратор создаётся локальной CLI, остальных сотрудников создаёт admin.
Публичный signup отсутствует. Пять ролей и собственные сессии защищены на backend.
Локальные аккаунты помечены demo; реальная SMS-проверка и восстановление не имитируются.

Заказов на этом этапе нет. Следующий модуль должен обеспечить гостевой ownership
непрозрачным секретом; телефон сам по себе не предоставляет доступ. Лимиты активных
гостевых заказов, восстановление доступа и защита от злоупотреблений уточняются в ORDERS-01.

Связи: [аутентификация](../authentication.md), [авторизация](../authorization.md),
[задача](../../../tasks/IDENTITY-01.md).

Альтернатива: клиентские аккаунты с регистрацией — исключена решением владельца.
Следствие: восстановление гостевого доступа и ограничения заказов нельзя привязать
к обязательной учётной записи; это отдельная часть ORDERS-01.
