# Рецепты и производство

PRODUCTION-01 реализует версии рецептов, фактический расход и атомарный выпуск.
[Порядок работы](../engineering/production-usage.md),
[ADR-0010](../architecture/decisions/0010-production-transactions.md).
ORDERS-01 резервирует существующие готовые партии по FEFO. KITCHEN-01 выдаёт готовые партии, не создавая новый выпуск и не расходуя сырьё повторно.

Рецепт хранит версию, норму сырья, единицы, ожидаемый выход и размер порции.
«1 кг → 12 порций» нужно определить: масса сырого риса или готового блюда; не считать это
универсальной нормой. Плановый выход отличается от фактического.

Процесс: выбрать рецепт → указать фактический расход → подтвердить пригодность/наличие сырья →
записать фактический выход → атомарно списать сырьё и добавить готовую партию.
Для MVP подтверждённый выпуск является точкой записи расхода; учёт незавершённого производства
может быть добавлен позже. Дефицит хотя бы одного ингредиента откатывает весь выпуск.

Каша утром, первый котёл на обед, второй котёл позже — разные партии с общим видом товара.
Резервы распределять по пригодным партиям, предпочтительно с ближайшим сроком реализации.
Собственная сомса использует рецепт; покупная сомса — обычный приход без повторного списания сырья.
После продажи порции ингредиенты повторно не списываются. Отмена заказа не возвращает сырой рис.

Неверный выпуск корректируется отдельной операцией; если часть уже продана/зарезервирована,
нельзя просто удалить выпуск. Потребуются разбор затронутых заказов и компенсирующие движения.
