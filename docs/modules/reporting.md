# Отчёты

REPORTS-01 реализован. [Инструкция](../engineering/reporting-usage.md),
[ADR-0015](../architecture/decisions/0015-read-only-reports.md).

Четыре отчёта: продажи по событиям, фактическое производство, текущий остаток,
списания/расхождения пересчёта. Право reporting.read проверяется backend при каждом запросе.
Даты — включительные дни Алматы; товарный фильтр везде; период питания, канал online/cashier,
mode mock/real только в продажах. Показан момент актуальности. Итоги полные до pagination.

Оплата и выдача раздельны. Pending/failed/timeout не входят в поступления; отмена после оплаты
показывает отдельный возврат. POS success — немедленная оплата/выдача. Неявка ещё не реализована.
Mock не является реальной выручкой; реальная оплата не подключена, соответствующий режим пуст.
Единицы количеств не смешиваются. Денежные/Decimal-агрегаты не теряют точность в браузере.

Метод себестоимости по фактическим партиям принят в [ADR-0021](../architecture/decisions/0021-finance-and-payroll.md);
прибыль считает модуль [финансов](finance.md). Исторические остатки, экспорт и финансовая сверка
не входят в REPORTS-01. Журналы не редактируются, персональные данные в отчёт не включаются.
