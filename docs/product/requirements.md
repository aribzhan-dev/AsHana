# Требования

Статусы: **Подтверждено** — запрос владельца; **Предложено** — проектное решение для обсуждения;
**Реализовано** — только после работающего кода и проверок.
FOUNDATION-01 покрывает основу R11/R12/R13/R16/R17/R18. IDENTITY-01 реализует R14/R15
для форм сотрудников и применяет R11–R13/R16/R18. UI-01 добавляет общие компоненты,
иконки темы, placeholder телефона, формы и мобильный кабинет; QuantityInput подготовлен,
INVENTORY-01 применяет числовые поля, Decimal-учёт, партии, списания и пересчёт.
PRODUCTION-01 реализует R05/R06/R07: версии рецептов, фактические расходы и готовые партии.
CATALOG-01 реализует показ R01 и готовых товаров R06: периоды, публикация, порция, цена,
пригодный свободный остаток. Нулевые позиции скрыты. Заказы и продажи ещё впереди.
Подтверждено владельцем 20.10.2026: клиент без регистрации и входа; сотрудники входят
по логину/паролю от администратора. Телефон — необязательный контакт, только KZ MOBILE.

|---|---|---|---|
